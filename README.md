# AgentURA

**Multi-Agent AI Orchestration Platform**

AgentURA არის მძლავრი და მოქნილი multi-agent სისტემა, რომელიც საშუალებას გაძლევს შექმნა, მართო და კოორდინაცია გაუწიო რამდენიმე სპეციალიზებულ AI აგენტს. პლატფორმა დაფუძნებულია თანამედროვე agentic architecture-ზე და შესაფერისია როგორც პერსონალური, ისე ბიზნეს გამოყენებისთვის.

---

## ✨ ძირითადი უპირატესობები

- **100+ სპეციალიზებული აგენტი** — Coding, Research, Analysis, Content Creation, SEO, Testing და სხვა
- **Agent Swarms** — აგენტების გუნდური და კოორდინირებული მუშაობა
- **Self-Learning Memory** — აგენტები სწავლობენ და იხსენებენ წინა გამოცდილებას
- **Multi-Model მხარდაჭერა** — Claude, GPT, Gemini, Ollama და სხვა LLM-ები
- **Web UI + CLI** — მოსახერხებელი ინტერფეისები
- **მარტივი გაფართოება** — საკუთარი აგენტებისა და ინსტრუმენტების დამატება
