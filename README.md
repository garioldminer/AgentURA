# AgentURA

**შენი პერსონალური Multi-Agent AI გუნდი**

AgentURA არის მძლავრი AI აგენტების პლატფორმა, რომელიც საშუალებას გაძლევს შექმნა და მართო რამდენიმე სპეციალიზებული AI აგენტი, რომლებიც ერთად მუშაობენ შენს ამოცანებზე.

---

## ✨ ძირითადი შესაძლებლობები

- 100+ სპეციალიზებული AI აგენტი (კოდერი, რისერჩერი, რევიუერი, SEO სპეციალისტი, მარკეტერი და სხვ.)
- Agent Swarms — აგენტების გუნდური მუშაობა
- Self-learning Memory (აგენტები იხსენებენ წინა დავალებებს)
- მხარდაჭერა Claude, GPT, Gemini, Ollama და სხვა მოდელების
- Web UI + CLI ინტერფეისი
- მარტივი გაფართოება და საკუთარი აგენტების დამატება
